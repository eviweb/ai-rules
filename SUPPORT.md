# Support

## Getting help

- **Bug reports and feature requests**: open an issue on
  [GitHub](https://github.com/eviweb/ai-rules/issues)
- **Security vulnerabilities**: see [SECURITY.md](SECURITY.md) — do not
  open a public issue
- **Questions and discussion**: use
  [GitHub Discussions](https://github.com/eviweb/ai-rules/discussions)

## Before opening an issue

1. Check the [README](README.md) for installation and usage instructions
2. Search existing [issues](https://github.com/eviweb/ai-rules/issues) to
   avoid duplicates
3. Run `ai-rules --help` and `ai-rules status` to gather diagnostic information

## Providing useful context

When opening an issue, include:
- Output of `ai-rules --version`
- Output of `ai-rules status` (if relevant)
- Your OS and shell (`uname -a`, `echo $SHELL`)
- Full error message or unexpected output
